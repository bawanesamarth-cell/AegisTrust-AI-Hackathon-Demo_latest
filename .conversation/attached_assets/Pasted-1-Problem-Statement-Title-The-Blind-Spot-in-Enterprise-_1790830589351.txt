1. Problem Statement
Title: The Blind Spot in Enterprise Agentic AI — Unmonitored Runtime Threat & Privacy Risks
Modern enterprises are rapidly adopting autonomous AI agents and Generative AI workflows to automate customer support, financial operations, internal knowledge retrieval, and software execution. However, current security controls operate at the static infrastructure layer (firewalls, API gateways) rather than the dynamic context layer where LLM decisions occur.

This creates critical security, privacy, and regulatory vulnerabilities:

Indirect Prompt Injections & Jailbreaks: Adversaries insert malicious instructions into unstructured data (e.g., poisoned emails, uploaded PDFs, database records) that override an agent's system instructions, tricking it into leaking data or triggering malicious API calls.

PII/PHI Exfiltration to Third-Party Models: Users and internal staff inadvertently paste sensitive customer PII, health records (PHI), or confidential financial data into prompts sent to external public LLMs (e.g., OpenAI, Anthropic).

Unbounded Agent Action Scope (Shadow AI Execution): Agents given function-calling capabilities often execute database modifications or system calls beyond their authorized access boundaries without real-time policy checks.

Lack of Verifiable Compliance & Audit Trails: Standard enterprise logs are text-based and prone to tampering, making it impossible to audit nondeterministic AI decisions during regulatory reviews (e.g., EU AI Act, HIPAA, SOC 2).

2. Solution Description
Project Name: AegisTrust AI — Zero-Trust AI Governance & Defense Runtime Engine
AegisTrust AI is a real-time, high-throughput sidecar proxy gateway and control plane that intercepts, inspects, redacts, validates, and audits every prompt, agent action, and tool invocation in real time before it reaches underlying AI models or enterprise microservices.

Key Application Features
Neural Injection Guardrail: Uses a fine-tuned lightweight classifier combined with semantic embeddings to analyze prompt intent in under 15 milliseconds, detecting direct and indirect prompt injections with >99% accuracy.

Vaultless Contextual PII/PHI Tokenization: Automatically replaces names, SSNs, credit cards, and addresses with format-preserving surrogate tokens before sending data to external APIs. Sensitive values are re-hydrated only on the outbound response path for authenticated, authorized users.

ABAC Tool Invocation Sandbox: Enforces Attribute-Based Access Control on agent function calls. Even if an LLM generates a function call like delete_account() or query_salary(), AegisTrust validates the user's active session token before allowing execution.

Cryptographic Merkle Tree Audit Ledger: Hashes every input, sanitized prompt, model action, and policy decision into a tamper-evident Merkle ledger, enabling simple regulatory reporting for HIPAA, GDPR, and the EU AI Act.

Real-time Security Dashboard: An interactive Web UI providing security operations teams (SecOps) with live threat tracking, attack vectors, PII reduction metrics, and interactive prompt testing sandboxes.

# AegisTrust AI - Zero-Trust AI Runtime Governance Engine

## Prerequisites
- Docker & Docker Compose (v2.20+)
- Python 3.11+ / Node.js 20+ (for local development)
- OpenAI API Key or Local Ollama Endpoint

## Quickstart via Docker Compose

1. Clone the Repository:
   git clone https://github.com/your-org/aegistrust-ai.git
   cd aegistrust-ai

2. Configure Environment Variables:
   cp .env.example .env
   # Edit .env and insert your LLM API keys and JWT secret keys

3. Launch Services:
   docker-compose up --build -d

4. Access the Application:
   - Frontend Dashboard: http://localhost:3000
   - Gateway API Docs: http://localhost:8000/docs
   - Metrics Endpoint: http://localhost:8000/metrics

   cd backend && pytest
